## تعریف معیار موفقیت هر فاز

این معیارها با اهداف کسب‌وکار، KPIها و SLO/SLIهای تعریف‌شده هم‌راستاست و به‌صورت قابل‌سنجش تنظیم شده‌اند.


### فاز 1 (MVP)
- قابلیت‌ها
  - ثبت/ویرایش/جستجوی بیمار و یک رکورد بالینی: Done با تست‌های یکپارچه
  - آپلود DICOM تک‌فایل و اتصال به رکورد: Done با کنترل اندازه/فرمت
  - پیش‌بینی پایه (Alzheimer/Parkinson) + گزارش PDF ساده: Done
- کیفیت/کارایی
  - CRUD p95 latency ≤ 600ms؛ p99 ≤ 1s
  - Prediction همگام ≤ 2s برای ورودی استاندارد
  - آپلود 100MB: اعتبارسنجی اولیه ≤ 2s (پردازش آسنکرون خارج از MVP)
  - Uptime ماهانه ≥ 99.5%
- امنیت/انطباق
  - RBAC پایه در مسیرهای کلیدی، JWT، هدرهای امنیتی
  - Rate Limiting مسیرمحور: login/upload/CRUD فعال
  - لاگ ممیزی برای عملیات حساس
- تست/کیفیت
  - پوشش تست Backend/Frontend ≥ 60%
  - SAST در CI (High/Critical=0)، DAST سبک در Stage
  - بدون نشت داده حساس در لاگ‌ها


### فاز 2
- قابلیت‌ها
  - طولی: Episode/Visit + نمودار روند، گزارش‌های بهبود‌یافته
  - یکپارچگی یک‌طرفه HIS/PACS (Pull Batch) با قرارداد روشن
  - داشبورد مدیریتی عملیاتی (Uptime/Latency/Error/RPS)
- کیفیت/کارایی
  - CRUD/Longitudinal p95 ≤ 600ms، صفحات طولی بارگذاری پایدار
  - Uptime ماهانه ≥ 99.7%
  - کاهش خطاهای 5xx به ≤ 1% از کل درخواست‌ها
- امنیت/انطباق
  - CSP Report-Only و بهبود هدرها
  - فرآیند DSR پایه (حذف/ناشناس‌سازی) مستند و آزمون‌شده در Stage
- تست/کیفیت
  - پوشش تست ≥ 65–70% و چند سناریو E2E حیاتی
  - DAST شبانه در Stage، Quality Gates فعال


### فاز 3
- قابلیت‌ها
  - هشدارهای طولی و آستانه‌های قابل تنظیم
  - Explainability بهتر (Feature Importance/هایلایت ابتدایی)
  - گزارش‌های زمان‌بندی‌شده (Scheduled)
  - صف آسنکرون برای پردازش‌های سنگین (PDF/Sync Batch)
- کیفیت/کارایی
  - حفظ SLOها با افزایش بار: p95 ≤ 600ms، Prediction همگام ≤ 2s یا آسنکرون پایدار
  - مصرف صف پایدار (Queue depth کنترل‌شده)، نرخ موفق > 99%
  - Uptime ماهانه ≥ 99.8%
- امنیت/انطباق
  - MFA برای نقش‌های حساس، IP Whitelist اختیاری
  - Idempotency-Key برای POSTهای حساس و وب‌هوک‌ها
  - DR Drill فصلی موفق (RPO/RTO مطابق سیاست)
- تست/کیفیت
  - پوشش تست ≥ 70–75%، تست بار سبک برای مسیرهای حیاتی
  - تریسینگ (OTel) برای مسیرهای کلیدی فعال


### فاز 4
- قابلیت‌ها
  - یکپارچگی دوطرفه HIS/PACS، مدیریت نسخه مدل، Drift Monitoring و Rollback
  - استقرار بدون وقفه (Canary/Blue-Green) در Prod
- کیفیت/کارایی
  - Uptime ماهانه ≥ 99.9%
  - Error Budget رعایت‌شده؛ توقف خودکار rollout در عبور از آستانه
  - بهینه‌سازی هزینه: کاهش هزینه هر پیش‌بینی/گزارش با حفظ SLOها
- امنیت/انطباق
  - DPIA تکمیل و ممیزی‌های دوره‌ای موفق
  - رمزنگاری در سکون برای داده‌های حساس و بکاپ‌ها
- تست/کیفیت
  - پوشش تست پایدار ≥ 75%+، تست نفوذ دوره‌ای (در صورت سازمان)


### نحوه سنجش و گزارش‌دهی
- داشبوردهای Grafana: Latency/Error/RPS/Uptime/Queue depth
- گزارش‌های ماهانه KPI: پذیرش (MAU/Retention)، کیفیت مدل (AUC/F1)، زمان تا نتیجه (TTR)
- مرور Postmortem برای رخدادهای Sev-1/2 و پیگیری اقدامات اصلاحی

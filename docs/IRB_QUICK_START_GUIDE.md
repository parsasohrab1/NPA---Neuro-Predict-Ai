## 📋 گام‌های اولیه (هفته 1-2)

### گام 1: آماده‌سازی تیم

#### الف. تشکیل تیم تحقیق
```
✅ وظایف اصلی:
  - محقق اصلی (Principal Investigator - PI)
  - هماهنگ‌کننده تحقیق (Research Coordinator)
  - مدیر داده (Data Manager)
  - آماردان (Biostatistician)
  - مشاور طب اعصاب (Neurology Consultant)
  - مسئول انطباق (Compliance Officer)
```

#### ب. آموزش‌های مورد نیاز
1. **CITI Program - Human Subjects Protection**
   - لینک: https://about.citiprogram.org/
   - مدت زمان: 4-6 ساعت
   - اعتبار: 3 سال
   - الزامی برای: تمام اعضای تیم تحقیق

2. **Good Clinical Practice (GCP)**
   - لینک: https://ichgcp.net/
   - مدت زمان: 2-4 ساعت
   - الزامی برای: محققان و هماهنگ‌کنندگان

3. **HIPAA Privacy Training**
   - مدت زمان: 1-2 ساعت
   - الزامی برای: کارکنانی که با PHI کار می‌کنند

```bash
# چک‌لیست آموزش تیم
- [ ] محقق اصلی: CITI + GCP + HIPAA
- [ ] هماهنگ‌کننده تحقیق: CITI + GCP + HIPAA
- [ ] مدیر داده: CITI + HIPAA + Data Security
- [ ] سایر اعضا: CITI + HIPAA
```

### گام 2: بررسی الزامات سازمانی

#### الف. شناسایی کمیته IRB صلاح
```
گزینه‌ها:
1. IRB سازمانی (Institutional IRB)
   - مزایا: آشنایی با محیط، فرآیند سریع‌تر
   - معایب: ممکن است برای مطالعات چندمرکزی محدود باشد

2. IRB مرکزی (Central IRB)
   - مزایا: مطالعات چندمرکزی، تخصص بیشتر
   - معایب: ممکن است هزینه بیشتری داشته باشد

3. IRB تجاری (Commercial IRB)
   - مزایا: سریع‌تر، انعطاف‌پذیرتر
   - معایب: هزینه بالاتر
```

#### ب. دریافت اطلاعات IRB
```
اطلاعات مورد نیاز:
- فرم‌های درخواست IRB
- راهنمای ارسال
- الزامات خاص سازمانی
- جدول زمانی جلسات IRB
- هزینه‌های ارسال
- نمونه‌های اسناد تأییدشده
```

### گام 3: جمع‌آوری اسناد پشتیبان

#### الف. اسناد شخصی
```bash
# برای هر محقق:
- [ ] رزومه (CV) به‌روز (تاریخ 2 سال اخیر)
- [ ] گواهینامه‌های آموزشی (CITI, GCP, HIPAA)
- [ ] گواهینامه پروانه طبی (در صورت وجود)
- [ ] بیانیه تضاد منافع
```

#### ب. اسناد سازمانی
```bash
- [ ] نامه حمایت از مؤسسه
- [ ] توضیحات امکانات و تجهیزات
- [ ] گواهینامه‌های اعتبار آزمایشگاه (CLIA, CAP)
- [ ] بیمه مسئولیت حرفه‌ای
- [ ] قراردادهای همکاری (در صورت چندمرکزی بودن)
```

### روش ارسال

#### گزینه 1: ارسال آنلاین (ترجیح)
```
1. ورود به سیستم IRB سازمان

3. تکمیل فرم آنلاین
4. آپلود تمام اسناد
5. بررسی و ارسال
6. دریافت شماره تأیید
```

#### گزینه 2: ارسال کاغذی
```
1. چاپ تمام اسناد (3 نسخه)
2. سازماندهی در پوشه
3. برچسب‌گذاری واضح
4. ارسال به دفتر IRB
5. دریافت رسید
```

## ⏰ بعد از ارسال: انتظار برای بررسی

### جدول زمانی معمول

```
هفته 1-2: بررسی اولیه توسط کارمندان IRB
  - بررسی کامل بودن
  - بررسی مطابقت با مقررات
  - ممکن است سؤالات اولیه بیاید

هفته 3-4: بررسی توسط اعضای IRB
  - اختصاص به بازبین اولیه و ثانویه
  - بررسی علمی و اخلاقی
  - آماده‌سازی برای جلسه

هفته 5-6: جلسه IRB
  - ارائه پروژه (ممکن است از شما خواسته شود حضور داشته باشید)
  - بحث کمیته
  - رأی‌گیری

هفته 7-8: دریافت تصمیم
  - تأیید (Approved)
  - تأیید مشروط (Conditionally Approved)
  - اصلاحات مورد نیاز (Modifications Required)
  - موکول شده (Deferred)
  - رد شده (Disapproved)
```

### پاسخ‌های ممکن

#### 1. تأیید (Approved) ✅
```
تبریک! مطالعه شما تأیید شده است.

گام‌های بعدی:
- [ ] دریافت نامه تأیید رسمی
- [ ] یادداشت تاریخ انقضا (معمولاً 1 سال)
- [ ] شروع فعالیت‌های قبل از شروع مطالعه
- [ ] آموزش کارکنان
- [ ] راه‌اندازی سیستم‌های داده
- [ ] شروع جذب
```

#### 2. تأیید مشروط (Conditionally Approved) 🟡
```
مطالعه شما تقریباً آماده است، اما نیاز به تغییرات جزئی دارد.

معمولاً شامل:
- تصحیحات رضایت‌نامه
- روشن‌سازی پروتکل
- اسناد اضافی

گام‌های بعدی:
- [ ] بررسی دقیق نظرات IRB
- [ ] انجام تغییرات درخواستی
- [ ] ارسال پاسخ و اسناد بازنگری شده
- [ ] انتظار برای تأیید نهایی (معمولاً 1-2 هفته)
```

#### 3. اصلاحات مورد نیاز (Modifications Required) 🟠
```
تغییرات قابل توجهی مورد نیاز است.

ممکن است شامل:
- تغییرات اساسی پروتکل
- بازنگری ارزیابی ریسک
- تغییرات روش‌شناسی

گام‌های بعدی:
- [ ] ملاقات با کارمندان IRB (توصیه می‌شود)
- [ ] انجام تغییرات اساسی
- [ ] ارسال مجدد (ممکن است نیاز به بررسی کامل مجدد باشد)
- [ ] انتظار برای جلسه IRB بعدی
```

#### 4. موکول شده (Deferred) 🔴
```
IRB نیاز به اطلاعات یا توضیحات بیشتری دارد.

دلایل معمول:
- نگرانی‌های علمی یا اخلاقی
- اطلاعات ناقص
- سؤالات اساسی

گام‌های بعدی:
- [ ] بررسی دقیق نامه موکول شدن
- [ ] ملاقات با صندلی/کارمندان IRB
- [ ] رسیدگی به نگرانی‌ها
- [ ] ارسال پاسخ جامع
- [ ] آماده‌سازی برای جلسه بعدی
```

## 📊 ردیابی پیشرفت

### معیارهای کلیدی (KPIs)

```python
# اسکریپت ساده Python برای ردیابی

import pandas as pd
from datetime import datetime

# معیارها
metrics = {
    'تاریخ_تأیید_IRB': '2025-XX-XX',
    'تعداد_شرکت_کنندگان_هدف': 1000,
    'تعداد_فعلی': 0,
    'نرخ_جذب_هدف_ماهانه': 67,  # 1000/15 ماه
    'نرخ_واجد_شرایط': 0.7,  # 70% واجد شرایط
    'نرخ_ثبت_نام': 0.8,  # 80% ثبت‌نام پس از واجد شرایط
}

# محاسبه تماس‌های مورد نیاز
contacts_needed = metrics['نرخ_جذب_هدف_ماهانه'] / (
    metrics['نرخ_واجد_شرایط'] * metrics['نرخ_ثبت_نام']
)
print(f"تماس‌های مورد نیاز در ماه: {contacts_needed:.0f}")
```

## 🎯 نکات موفقیت

### ✅ کارهایی که باید انجام دهید

1. **شروع زود**: 2-3 ماه قبل از تاریخ شروع هدف
2. **ارتباط زود هنگام**: با دفتر IRB تماس بگیرید، سؤالات بپرسید
3. **استفاده از قالب‌ها**: از قالب‌های تأییدشده سازمان استفاده کنید
4. **بررسی توسط همتایان**: از همکاران بخواهید اسناد شما را بررسی کنند
5. **سادگی**: زبان ساده، توضیحات واضح
6. **کامل بودن**: تمام سؤالات را پاسخ دهید، اسناد را فراموش نکنید
7. **سازگاری**: اطمینان حاصل کنید پروتکل و رضایت‌نامه هماهنگ هستند

### ❌ کارهایی که نباید انجام دهید

1. **عجله نکنید**: ارسال ناقص = تأخیرها
2. **فرض نکنید**: از IRB بپرسید اگر مطمئن نیستید
3. **کپی-پیست نکنید**: رضایت‌نامه‌ها را برای مطالعه خود تنظیم کنید
4. **ژارگون استفاده نکنید**: از زبان ساده استفاده کنید
5. **اسناد را فراموش نکنید**: همه چیز را دوباره بررسی کنید
6. **ضرب‌الاجل‌ها را نادیده نگیرید**: پاسخ به موقع به IRB
7. **آموزش را نادیده نگیرید**: اطمینان حاصل کنید همه به‌روز هستند

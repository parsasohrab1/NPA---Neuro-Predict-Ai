## دسترس‌پذیری (A11y)، SEO، و پرفورمنس (LCP/CLS/TTI)

### دسترس‌پذیری (A11y)
- ساختار معنایی: استفاده از نقش‌ها/تگ‌های مناسب (`main`, `nav`, `header`, `footer`, `section`, `button`, `label`).
- کنتراست و تایپوگرافی: WCAG AA، اندازه قلم حداقلی خوانا، فاصله خطوط مناسب.
- فوکوس: حلقه فوکوس واضح، ترتیب تب منطقی، trap فوکوس در Modal/Drawer.
- فرم‌ها: `label for` و `id` یکتا، helper/error text نزدیک کنترل، پیام‌های خطای خوانا.
- تصاویر/آیکون‌ها: `alt` معنادار، ARIA برای آیکون‌های تزئینی (`aria-hidden="true"`).
- جدول/لیست: هدرهای جدول (`th`/`scope`)، عناوین قابل‌فهم برای خواننده صفحه.
- کیبورد: همه تعاملات با کیبورد قابل انجام باشد؛ میانبرهای کلیدی مستند (در صورت نیاز).
- اعلان‌ها: Toast/Alert با ARIA live regions برای اعلام وضعیت‌ها.
- RTL/i18n: جهت‌دهی صحیح، تاریخ/عدد RTL-friendly، کلیدهای ترجمه پایدار.


### SEO (مناسب برای SPA)
- متاهای پایه: `title`, `meta description`, `lang="fa"`, `dir="rtl"`، آیکون‌ها.
- Open Graph/Twitter: `og:title`, `og:description`, `og:type`, `og:image` (در صورت نیاز).
- ساختار URL و روتینگ: مسیرهای انسانی و پایدار؛ نقشه سایت (در صورت SSR/Static).
- محتوای قابل ایندکس: در صورت نیاز SEO قوی، بررسی SSR/Pre-render (Next.js گزینه آتی).
- عملکرد: LCP/TTI خوب به بهبود سئو کمک می‌کند.


### پرفورمنس (Core Web Vitals)
- اهداف (پیشنهادی):
  - LCP ≤ 2.5s (خوب)، CLS ≤ 0.1، TTI ≤ 3.5s
- LCP:
  - بهینه‌سازی تصویر LCP (فرمت مدرن، اندازه مناسب، lazy برای غیرقابل‌مشاهده).
  - کاهش بلاکینگ: کاهش اسکریپت‌های غیرضروری، تقسیم کد (code-splitting).
  - کش و CDN برای دارایی‌ها.
- CLS:
  - تعیین ابعاد برای تصاویر/ویدیوها، skeleton با اندازه ثابت، اجتناب از تزریق‌های late بدون فضا.
- TTI/TBT:
  - کاهش JS سنگین، تعویق اسکریپت‌های غیرحیاتی (`defer`/dynamic import).
  - استفاده از memoization و virtualization برای لیست‌های بزرگ.
- شبکه و کش:
  - HTTP compression (gzip/br), long-term caching با hash، preconnect/preload برای منابع مهم.
- اندازه باندل:
  - tree-shaking، حذف وابستگی‌های سنگین/بی‌استفاده، استفاده از آیکون‌های برداری/inline.


### اندازه‌گیری و پایش
- ابزار توسعه: Lighthouse، Web Vitals، React Profiler، Coverage.
- پایش واقعی کاربر (RUM): جمع‌آوری Web Vitals (اختیاری) بدون PII/PHI.
- داشبورد: گزارش دوره‌ای LCP/CLS/TTI و روند بهبود.
